Descripción:
Colección de ejercicios de POO (abstracción, encapsulación, herencia simple, polimorfismo y herencia múltiple) implementados en Java.

Compilar y ejecutar:
- Compilar: mvn compile
- Ejecutar (ejemplo, ejercicio1):
  java -cp target/classes com.ues.drs.ejercicio1_abstracion.Main
  Cambiar el paquete.Main según el ejercicio que quiera ejecutar.

Estructura principal:
- src/main/java/...  -> código fuente
- target/classes     -> clases compiladas
- pom.xml            -> proyecto Maven

Indicaciones:
- Actividad en parejas; subir todo a un repositorio público en GitHub.
- Trabajo original; documentar brevemente cada ejercicio (propósito y cómo ejecutar).
